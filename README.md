# Kafela's Agenda

Aplikasi manajemen jadwal agenda studio kreatif, kasir cepat (POS), cetak struk pembayaran (Thermal Bluetooth & A4), laporan keuangan, portofolio web studio, dan formulir booking online.

## Menjalankan Lokal

1. Instal dependensi: `npm install`
2. Salin `.env.example` menjadi `.env` dan isi konfigurasi Firebase proyek Anda.
3. Jalankan server pengembangan: `npm run dev`
4. Bangun versi produksi: `npm run build`
